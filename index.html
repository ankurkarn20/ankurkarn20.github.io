// featured project

CampusGPT: an AI helpdesk that can't leak student data

My final-year project: a full-stack AI assistant that answers university students' questions about their own records and the university's rules, in English and Hinglish.

Final-year project · 2026
  • Secure by design: the language model never touches the database. It can only call read-only tools, and the student's identity always comes from the login session, so no prompt can make it fetch another student's records.
  • Hybrid search over policy documents (RAG): BGE embeddings with a pgvector HNSW index plus PostgreSQL full-text search, merged by Reciprocal Rank Fusion. Every citation is checked against the passages actually retrieved.
  • Runs fully locally: Qwen3 4B on a laptop GPU through Ollama, switchable to a hosted model (GPT-OSS 120B on Groq) behind a provider adapter.
  • Red-teamed: an automated suite of 9 attacks (impersonation, jailbreaks, smuggled tool arguments, SQL injection, Hinglish social engineering), judged by code, not by the model.
  • Synthetic university with 5,000 students, admin document pipeline with a background worker, audit log, rate limiting, calendar export, and a 50-question benchmark.
